Ibex Capability Security rev2

Typed effects, per-package principals, digest-bound policy, and fail-closed startup.

Production has one posture

--capsec permissive · --capsec enforce · --lockdown

ibex run app.js is already enforce + lockdown.

An unsupported target, malformed policy, or stale digest refuses; it never selects a weaker mode.

Policy is generated evidence

  • Exact package locator + integrity identify each principal.
  • Typed resources replace colon-delimited capability strings.
  • Import-site provenance explains every positive authority row.
  • ibex policy check --entry app.mjs detects drift.

Authority is not reachability

A package can have permission for an effect without receiving an ambient global that invokes it. Endowments and host-boundary authority are separate gates.

Audit is explicit and ephemeral

ibex capsec audit app.js

Foreground audit is a diagnostic workflow. It is not a durable policy mode and cannot consume ambient endowment overrides.
