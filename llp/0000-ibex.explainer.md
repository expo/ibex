## Overview

Ibex is the Ibex 2 runtime. It supplies a Rust standard library, JavaScript
bindings, a capability-carrying host boundary, and an optional adapter for a
pinned unmodified Hermes engine. The workspace crates are `ibex2` (the Rust
library and optional engine-free JSI bindings), `ibex2-runtime` (the owning
runtime), `hermes-lean-sys` (the engine resolution/link boundary), and
`ibex2-sqlite` (the optional native SQLite provider).

Ibex 1, its patched engine, its application/platform code, and its SFE
packaging are outside this repository. Historical references to those systems
use commit-pinned URLs into the archived `expo/ibex1` repository.

## Repository invariants

- `ibex2` always builds without a VM. Its `bindings` feature is off by default
  and compiles against JSI headers while leaving the engine to the caller.
- `ibex2-runtime` is the only owning runtime and links its VM through
  `hermes-lean-sys`; the same resolution supplies the bindings' `hermesc`.
- Authority is explicit at the Rust boundary; JavaScript bindings do not infer
  ambient authority.
- `./ref-check` validates LLP metadata, overlays, and `@ref` annotations.
